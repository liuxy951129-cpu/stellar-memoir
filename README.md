# 星海拾遗 · Stellar Memoir

> 在遗忘的银河里，重新爱你一次。  
> A space-station visual novel about love, memory, and the courage to recognize someone again.

## 玩法
- **品类**：恋爱 × 剧情 × 文字冒险（Galgame 风）
- **三条主线 × 3 天剧情**：千夜（理性）/ 云璃（感性）/ 银（反差）
- **多结局**：基于好感度与 flag 自动判定 HE / NE / TE
- **回忆相册**：每解锁一段 CG 永久收藏
- **记忆抽取（抽卡）**：星币消耗 / 十连保底 SSR / 隐藏 4 张限定 CG
- **存档 / 自动 / 跳过 / 日志 / 设置** 一应俱全

## 技术
- 纯前端 H5（无后端依赖）
- 立绘：纯 SVG 多层叠加（赛璐璐厚涂感，每角色独立调色板）
- 场景：CSS 渐变 + 多层光效合成
- 存档：localStorage

## 控制
- 点击对话框：推进 / 跳过打字
- 选项：直接点击
- 工具条：自动 / 跳过 / 日志 / 存档 / 读档
